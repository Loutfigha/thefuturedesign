# The Future Design — website

Statische website voor The Future Design (webdesign & digital marketing, Utrecht).
Platte HTML, CSS en JavaScript — geen framework, geen build-stap.

## Bekijken

Dubbelklik `index.html` om de site in je browser te openen.

Netter (nodig als je alles precies wilt zien zoals online):

```
python3 -m http.server 8000
```

Open daarna http://localhost:8000

## Pagina's

- `index.html` — homepage
- `diensten.html` + `webdesign.html`, `e-commerce.html`, `strategie.html`, `campagnes.html`
- `cases.html` + `case-rebrand.html`, `case-webshop.html`
- `over-ons.html`, `contact.html`

Styling staat in `style.css`, interactie in `main.js`.

## Nog in te vullen

- Voorbeeldcases vervangen door echte projecten
- Teamleden en foto's op `over-ons.html`
- Telefoonnummer (staat nu als `+31 0 000 000 00`)
- Contactformulier koppelen aan e-mail of CRM
- Agenda-embed (Cal.com of Calendly) in het boekingsblok
- Privacybeleid en algemene voorwaarden

Zie `CLAUDE.md` voor het design system en de afspraken bij verder bouwen.
